## Alternative evaluation template

- Original and candidate exact MPNs, manufacturer datasheets and revisions.
- Reason: availability, lifecycle, cost, package/assembly, performance, or repairability.
- Class: drop-in candidate / circuit redesign / PCB redesign / firmware change / architecture change.
- Pinout, exposed pad, land pattern, physical height, package tolerances.
- Operating voltages, absolute limits, logic thresholds, startup/reset behavior.
- Function-specific characteristics: IMU noise/ODR/driver; regulator compensation/transients; MOSFET gate charge/losses; RF matching/firmware/band support.
- Timing, thermals, EMI, calibration, manufacturing and testing implications.
- Required schematic/layout/firmware/BOM changes and linked decision.
- Tests and acceptance limits agreed before testing.
- Status: unverified candidate → datasheet reviewed → bench tested → system tested → approved for named revision.

Same package, similar headline ratings, or a seller's compatibility claim does not establish interchangeability. No substitution is approved until the affected design is reviewed and tested.
