# Upstream repository map

Snapshot: 2026-10-15, from https://github.com/orgs/OpenDrone-hw/repositories . These are upstream descriptions, not our validation results. Commit pinning remains pending.

| Area | Repository | Index description / caution |
|---|---|---|
| FC | https://github.com/OpenDrone-hw/OpenFC-Lite | RP2354B flight controller; beta label |
| FC | https://github.com/OpenDrone-hw/OpenFC-Lite-Mini | Smaller RP2354A flight controller; beta label |
| ESC | https://github.com/OpenDrone-hw/OpenESC-30x30 | Four-channel AM32 ESC; beta label |
| ESC | https://github.com/OpenDrone-hw/OpenESC-20x20 | Smaller four-channel AM32 ESC; beta label |
| Radio | https://github.com/OpenDrone-hw/OpenRX | Receiver family hub; follow links to board-specific sources |
| Libraries | https://github.com/OpenDrone-hw/KiCad-Library | Shared symbols, footprints, and models |
| Test | https://github.com/OpenDrone-hw/OpenDrone-Fixtures | Fixtures, flashing jigs, bench boards |
| Frame | https://github.com/OpenDrone-hw/OpenFrame-3F and https://github.com/OpenDrone-hw/OpenFrame-5F | Frame CAD references |
| Firmware | OpenDrone-hw/betaflight, betaflight-config, AM32, ExpressLRS | Hardware work may live on special branches |

The index describes some GPS, charger, and video projects as planned/incomplete. OpenMotor documents OEM motors rather than an open motor design. Therefore this collection must not be described as an already complete design for manufacturing every drone component ourselves.
